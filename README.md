# 中宏 · 成长闭环 Demo 打样 v1 — 部署说明

纯静态站点，三个 HTML 文件，零依赖、零构建。上传到任何静态托管即可。

## 页面路由

| 路径 | 内容 |
|---|---|
| `/` | 入口 · 两扇门 |
| `/qiuyan/` | 陈秋燕 · 新人面谈陪跑账本（晨 · 周期型） |
| `/wang/` | 王宇鹤 · 智能体体检中心（夜 · 测量型） |

## 部署方式（任选）

- **任意静态托管 / 对象存储**：保持目录结构原样上传即可，入口 `index.html`。
- **Nginx / 任意 Web 服务器**：把 `loop-demos` 目录作为站点根目录，无需 rewrite 规则（子页都是目录 + index.html 形式）。
- **本地预览**：`cd loop-demos && python3 -m http.server 8080`，访问 `http://localhost:8080/`。
- **Vercel / Netlify**：框架选 "Other / 无"，构建命令留空，输出目录设为根目录。

## 注意

- 页面内所有数据均为虚构演示数据。
- 中文衬线字体（宋体类）使用系统字体，macOS / Windows / iOS / Android 均可正常显示，无需额外字体文件。
